# Excel Lab 6 – Logical Functions and Decision-Making

## 📌 Overview

This lab focuses on using **Excel logical functions** to classify sales performance and handle errors in the DMart dataset.

## 🎯 Tasks Completed

* Classified sales using `IF`
* Applied **Nested IF** for detailed categorization
* Used `AND`, `OR`, and `NOT` for decision-making
* Handled errors using `IFERROR`

## 🛠️ Skills Used

* Microsoft Excel
* IF & Nested IF
* AND, OR, NOT
* IFERROR
* Data Analysis
* Business Logic

## 📊 Dataset

**DMart Retail Business Dataset**
